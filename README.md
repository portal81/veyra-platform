# Veyra Operations OS

Real Estate Delivery & Operations Platform.

## Setup

`ash
cp .env.example .env.local
npm install
npm run dev
`

## Stack

- **Framework:** Next.js 16 + React 19
- **Database:** Supabase (PostgreSQL)
- **Auth:** Supabase Auth + HMAC-SHA256 JWT sessions
- **Styling:** Tailwind CSS 4
- **Validation:** Zod 4
- **AI:** Groq (Hazem assistant)
